# 频谱仪使用说明

适用于本固件集成的 fagci 频谱分析仪（`app/spectrum.c`，编译开关 `ENABLE_SPECTRUM=1`，`make full` 的各变体均已包含）。

## 进入与退出

* **进入**：主界面按 **`F + 5`**（app/main.c:221）。若固件编译了 NOAA，则 `F+5` 被 NOAA 功能占用，无频谱入口。
* **退出**：扫描模式下按 **`EXIT`**，恢复进入前的频率和 BK4819 寄存器（`DeInitSpectrum`）。
* 频谱仪只支持机器当前允许的频段范围（`F_MIN` ~ `F_MAX`，由频段表决定）。

## 三种状态

| 状态 | 说明 |
|------|------|
| 扫描（SPECTRUM） | 频段扫描，显示频谱柱状图，自动监听峰值 |
| 单频测量（STILL） | 停在某频率，显示 S 表 / dBm，可调接收增益寄存器 |
| 频率输入（FREQ_INPUT） | 数字输入频率，`MENU` 确认 |

扫描模式按 `PTT` → 跳到当前峰值频率并进入单频测量；单频模式按 `EXIT` → 返回扫描。

## 扫描模式

### 屏幕显示

* **状态栏左**：纵轴显示范围 `-130/-50`（单位 dB，可调）；**状态栏右**：电池电量
* **第 2 行**：峰值频率、调制方式（FM/AM/USB）、监听带宽（25k/12.5k/6.25k）
* **左侧小字**：倍数（`128x/64x/32x/16x` 个测量点）与扫描步进（`25.00k` 等）
* **频谱区**：128 列柱状图；顶部三角箭头 = 峰值位置；横向虚线 = 触发阈值；底部刻度线在 10k/50k/100k 整数频率处加长
* **底行**：步进 < 2.5k 时为居中模式（`中心频率 ±步进`），否则显示起始频率 / 频率移动步进 / 终止频率

### 工作原理

1. 逐点测量 RSSI 画出柱状图，扫完一遍后若**峰值 ≥ 触发阈值**：自动调谐到峰值、开音频监听约 1 秒，然后继续扫描（spectrum.c:1478、1510）。
2. 纵轴下限 `dbMin` 会自动跟随扫到的最小信号（`UpdateScanInfo`），上限 `dbMax` 手动调。
3. 扫描步进改变 / 频率移动 / 黑名单都会重新开始一轮扫描。

### 按键

| 按键 | 功能 |
|------|------|
| `1` / `7` | 扫描步进 + / −（0.01k → 100k 共 15 档循环） |
| `2` / `8` | 频率移动步进 + / −（步进×4，100k ~ 2MHz） |
| `3` / `9` | 显示上限 dB + / − |
| `4` | 测量点数 16x ↔ 128x 循环（16x/32x/64x/128x） |
| `5` | 数字输入频率 |
| `0` | 切换调制方式 FM → AM → USB（含 BYP/RAW 的编译为 FM→AM→USB→BYP→RAW） |
| `6` | 监听带宽 25k / 12.5k / 6.25k |
| `↑` / `↓` | 平移扫描范围（按当前移动步进） |
| `*` / `F` | 触发阈值 + / −（虚线位置） |
| `侧键1` | **黑名单**：屏蔽当前峰值频率点，该点不再显示、不再触发监听 |
| `侧键2` | 背光常亮开关 |
| `PTT` | 跳到峰值频率，进入单频测量模式 |
| `EXIT` | 退出频谱仪 |

## 单频测量模式（STILL）

### 屏幕显示

* 频率 + 调制方式 + 带宽
* **S 表进度条**（带刻度）与阈值标记
* `S` 级、`当前dBm / 阈值dBm`
* 4 个寄存器值：`LNAs`、`LNA`、`PGA`、`IF`（选中项反白）

### 按键

| 按键 | 功能 |
|------|------|
| `MENU` | 循环选择要调的寄存器（LNAs → LNA → PGA → IF） |
| `↑` / `↓` | 未选寄存器时：微调频率（FM 1k / AM 0.5k / USB 0.1k）；已选寄存器时：修改该寄存器值 |
| `5` | 数字输入频率 |
| `0` | 切换调制方式 |
| `6` | 监听带宽 25k / 12.5k / 6.25k |
| `*` / `F` | 触发阈值 + / − |
| `3` / `9` | 显示上限 dB + / − |
| `侧键1` | **直通监听**开关（`monitorMode`，忽略阈值持续听） |
| `侧键2` | 背光常亮开关 |
| `EXIT` | 返回扫描模式（`lockAGC`、直通监听同时复位） |

### 寄存器说明

| 寄存器 | 位置 | 说明（原值越大增益越高，按 ↓ 降增益） |
|--------|------|--------------------------------------|
| LNAs | REG13 [8:9] | 粗调 LNA：3=0dB 2=-11dB 1=-16dB 0=-19dB |
| LNA | REG13 [5:7] | 细调 LNA：7=0dB … 0=-24dB |
| PGA | REG13 [0:2] | 可编程增益放大器：7=0dB … 0=-33dB |
| IF | REG3D | 中频增益（默认 0x2AAA） |

用途：弱信号时手动抬增益、强信号时压增益防过载。`F+5` 进入时会备份寄存器，退出时恢复。

## 频率输入

* `0`–`9` 输入数字，`*` 输入小数点（只能输入一次）
* `MENU` 确认：频率超出 `F_MIN` ~ `F_MAX` 时无效；在扫描模式下确认会清空黑名单并重新扫描
* `EXIT` 退格；输入框为空时再按 `EXIT` 返回上一状态

## 常用技巧

* **找信号**：进入后先按 `4` 选 16x（扫得快）粗扫，找到活动频段后再按 `4` 回到 128x 细看。
* **只关心某段**：按 `1/7` 改扫描步进缩小跨度，或用 `↑↓` 平移窗口。
* **听某个信号**：等峰值箭头停在信号上自动开听，或按 `PTT` 直接进单频模式慢慢调。
* **一直听**：单频模式按 `侧键1` 开直通监听。
* **避开干扰源**：扫描模式下把箭头移到干扰点按 `侧键1` 屏蔽（最多 15 个，仅本会话有效）。

## 注意事项

* **频谱设置不保存**：步进、阈值、点数、调制、带宽等都是运行时参数，不写 EEPROM，重启后恢复默认（spectrum.c:114）。
* **黑名单也是一次性的**：退出、改步进、平移频率都会清空。
* 扫描期间每轮只能在监听状态响应按键，等待约 0.1~1 秒属正常（扫描-监听循环）。
* AM 模式下若开启 AM Fix 会自动应用 AGC，RSSI 会做相应补偿（spectrum.c:435）。
* `PTT` 只在多普勒模式下才发射，普通单频测量模式不会发射。

## 与多普勒模式的关系（编译 `ENABLE_DOPPLER` 时）

* 频谱界面与多普勒模式复用：状态栏显示卫星名与 dB 范围，屏幕下方显示过境倒计时 / 进度条、Uplink/Downlink 频率。
* 进入时自动切到单频模式、FM 调制，频率跟随卫星下行频率自动更新。
* `PTT` = 发射（上行），松开停止；`EXIT` 直接退出频谱仪。
