# 原生 FM 广播使用说明

适用于本固件的原生调频收音机功能（`ENABLE_FMRADIO=1`，收音芯片 **BK1080**，代码 `app/fm.c`、`ui/fmradio.c`）。

> 与 SI4732 收音机互斥：`ENABLE_4732=1` 的变体会强制 `ENABLE_FMRADIO=0`（Makefile），此时 `F+0` 走 SI4732 界面。本文只讲原生 FM。

## 进入与退出

| 操作 | 说明 |
|------|------|
| 主界面 **长按 `0`** 或 **`F+0`** | 打开 FM 收音机（app/main.c:95、295） |
| FM 界面 **`F+0`** | 关闭 FM，返回对讲界面（fm.c:369 → ACTION_FM） |
| FM 界面 **`EXIT`**（无输入、无提示时） | 同上，退出 FM（fm.c:409） |
| 主界面 **`EXIT`**（FM 开着时） | 关闭 FM（main.c:499） |
| 发射/监听中 | 不允许开关 FM（action.c:426） |

进入 FM 时关掉对讲接收（`gDualWatchActive = false`），退出时恢复 VFO 配置。频率范围固定 **64.0 ~ 108.0 MHz**（settings.c:98 硬编码，单位 0.1MHz；有效存储台为 64.0 ~ 107.9）。

## 屏幕显示

```
FM                     ← 标题行
RSSI 187  SNR 12       ← 信号强度（原始值）
VFO                    ← 模式行
 96.0                  ← 频率 / 台号（大字）
[██████████░░░░░░]     ← 最底部：信号强度条
```

### 信号强度信息

* `RSSI`：BK1080 芯片读出的**原始值 0~255**（数值越大信号越强，芯片未公开换算成 dBµV 的公式，故不显示 S 级）。
* `SNR`：信噪比原始值 **0~15**（判台门槛为 >2，见 `FM_CheckFrequencyLock`）。
* 最底部为满宽信号条，按当前 RSSI 占满宽比例填充。
* 数值做了平滑处理，换台时立即复位为真实值；**每 0.5 秒自动刷新**，扫描时随每一步实时跳动。
* 数据在 FM 打开期间实时读取（`FM_GetSignalQuality` → `BK1080_GetSignalQuality`），关闭 FM 后不读芯片。

模式行含义（ui/fmradio.c）：

| 显示 | 含义 |
|------|------|
| `VFO` | 频率模式，当前频率未存入任何台 |
| `VFO(CH03)` | 频率模式，但该频率正好等于已存的 CH03 |
| `MR(CH05)` | 信道模式，正在播放 CH05 |
| `M-SCAN` | 手动扫描中 |
| `A-SCAN(n)` | 自动扫描中，正在存入第 n 台 |
| `保存?` | 确认保存提示（原码 `存置问`） |
| `删除?` | 确认删除提示（原码 `删除问`） |

频率显示格式 `%3d.%d`，如 `96.0`、`107.9`。

## 两种收听模式

### VFO 频率模式
* `↑`/`↓` 按 **0.1MHz** 步进调台，越过 108.0 自动回绕到 64.0（反之亦然），并自动保存当前频率（fm.c:544）。
* 可直接输频率（见下），也可按 `MENU` 把当前频率存成电台。

### MR 信道模式（本固件 **50 个台**）
* `↑`/`↓` 跳到上/下一个**已存**的电台，空台（0xFFFF）自动跳过（fm.c:537）。
* 没有任何有效电台时自动退回 VFO 并报错（`FM_ConfigureChannelState` 返回 -1）。
* `3` 键可在 VFO / MR 之间切换（fm.c:373）。
* 按 `MENU` 两次可删除当前台。

## 按键一览（FM 界面）

| 按键 | 功能 | 代码 |
|------|------|------|
| `↑`/`↓` | 调频率（VFO）/ 切台（MR）/ 扫描中手动步进 / 保存提示里选台号 | fm.c:506 |
| `0`–`9` | 输入频率（VFO）或台号（MR），保存提示里选存入的台号 | fm.c:259 |
| `MENU` | VFO：`保存?` → 再按保存；MR：`删除?` → 再按删除；扫描找到台后：`保存?` → 再按保存 | fm.c:453 |
| `EXIT` | 扫描中 = 停止扫描并播放；有输入 = 退格；有提示 = 取消；否则 = 退出 FM | fm.c:396 |
| `*` 短按 | **手动扫描 M-SCAN**（从当前频率向上扫，找到第一个台停下） | fm.c:385 → action.c:453 |
| `F+*` 或 长按 `*` | **自动扫描 A-SCAN**（⚠️ 先清空全部 50 个台，再从 64.0 扫到 108.0 自动填充） | 同上，`autoScan=true` |
| `3` 或 `F+3` | 切换 VFO ↔ MR | fm.c:373 |
| `0` 或 `F+0` | 关闭 FM | fm.c:369 |
| `F+1`/`F+2`/`F+4`~`F+9` | 无效，报错音 | fm.c:390 |
| `F` 短按 | 仅提示音（作为组合键前缀） | generic.c:99 |
| `PTT` | 扫描中 = 停止扫描；正常收听 = **直接发射**（切到对讲界面发话） | generic.c:148 |

## 数字输入规则

**VFO 模式输频率**（单位 0.1MHz，需凑满 4 位）：
* 首位 >1 时自动补 0：按 `9` `6` `0` → 实际解析 `0960` = 96.0MHz（fm.c:288）。
* 例：`1` `0` `7` `9` → 107.9；`8` `8` `1` → `0881` = 88.1。
* 输入不足 4 位不会生效；超出 64.0~108.0 报错音。
* 按 `EXIT` 退格。

**MR 模式输台号**：输 2 位数字，`01`–`50` → CH01–CH50（台号必须已存有有效电台，否则报错）。

**保存提示中输台号**：输 2 位数字直接选定存入的台号。

扫描进行中（非保存提示）数字键无效，报错音（fm.c:275）。

## 保存 / 删除电台

**保存（VFO → 台）**：
1. 调到想存的频率
2. 按 `MENU` → 显示 `保存?` 与当前台号
3. `↑`/`↓` 或直接输 2 位数字选台号（01–50）
4. 再按 `MENU` 确认保存（写入 EEPROM 并立即生效）

**删除（MR 模式）**：
1. 按 `MENU` → 显示 `删除?`
2. 再按 `MENU` 确认 → 该台写 0xFFFF，自动跳到下一个有效台

任意提示状态下按 `EXIT` 取消。

## 扫描

### M-SCAN 手动扫描
* 按 `*` 从当前频率以 **0.1MHz** 步进向上扫，每步约 **100ms**（`fm_play_countdown_scan_10ms`）。
* 每步调用 `FM_CheckFrequencyLock` 判定是否锁台（fm.c:215）：
  * SNR ≤ 2 → 无效
  * RSSI < 10 或 AFC 已失锁（railed）→ 无效
  * 频偏不在有效窗口 → 无效
* 找到台：开声音、置 `gFM_FoundFrequency`，画面保持 `M-SCAN`，可用 `MENU` 把它存进台。
* 停止：再按 `*`、`EXIT`、`PTT` 或 `F`（仅提示）→ `FM_PlayAndUpdate` 结束扫描状态。

### A-SCAN 自动扫描（⚠️ 有破坏性）
* `F+*` 或长按 `*` 触发：**先清空全部 50 个电台**（`FM_EraseChannels`），从 64.0MHz 起每 0.1MHz 步进扫描（action.c:472）。
* 每找到一个有效台存入下一个槽位（`A-SCAN(n)` 显示当前槽位），最多存满 50 台或扫到 108.0MHz 自动停止。
* 结束后自动切到 MR 模式并从 CH01 开始播放（fm.c:196）。
* 扫描中 `↑`/`↓`/数字键无效；`EXIT`/`PTT` 可中途停止（保留已存部分）。

### 判台与播放时序
* 手动调台后等 **1.2 秒**（`fm_play_countdown_noscan_10ms`）再检测锁台并开声，避免调台过程出声。
* 锁台成功后开音频通路（`AUDIO_AudioPathOn`），当前频率在非 MR 模式下会更新到 `FM_SelectedFrequency`。

## 与对讲功能的联动

* FM 收听中按 **PTT** → 直接进入发射（界面切回主界面，generic.c:162）。
* 扫描中按 **PTT** → 先停扫描，再发射。
* **发射/监听结束 5 秒后**自动回到 FM 界面继续播放（`gFM_RestoreCountdown_10ms`，functions.c:111、app.c:1228）。
* **写频/串口通信期间** FM 主循环暂停 2 秒（`gFmRadioCountdown_500ms`，uart.c）。
* FM 模式下双守候被禁用；频道扫描、DTMF 等与 FM 互不干扰。

## 存储与兼容性

| 项目 | 位置 |
|------|------|
| CH01–CH20 | EEPROM 0x0E40（与原厂兼容） |
| CH21–CH50 | EEPROM 0x02028（本固件扩展区，8 字节对齐，见 app/fm.h） |
| 当前频率/台号/模式 | EEPROM 0x0E88 |

* 每次调台、存台都会触发 `SETTINGS_SaveFM` 立即写入（app.c:1857）。
* 恢复出厂设置会清空全部电台（`FM_EraseChannels`）。
* ⚠️ PC 写频脚本 `写频脚本/uvk5_cn.py` 的 `fmfreq[20]` 只认识前 20 台（0x0E40），CH21–CH50 只能在机器上或用支持本固件的工具管理。

## 常见问题

* **打开没声音**：调台后需等 1.2 秒判台；弱信号可能因 SNR/RSSI 门槛被判为无效。
* **输频率没反应**：需按满 4 位（首位>1 自动补 0），且在 64.0–108.0 范围内。
* **`F+*` 后台全没了**：A-SCAN 会先清空 50 台再重扫，属预期行为。
* **存不了台**：台号必须在 01–50 之间；MR 模式下删除请按两次 `MENU`。
